Windows 2000 Installation

Released: 2000

▶ Watch on YouTube

Overview

Windows 2000 Professional brought NT technology to business desktops with improved Plug and Play support, better hardware compatibility, and Active Directory support.

Installation Steps

  1. Create a virtual machine with 256 MB RAM and 4 GB disk.
  2. Mount the Windows 2000 Professional ISO.
  3. Boot from the CD and press Enter to set up.
  4. Accept the license agreement.
  5. Create or select a partition and format as NTFS.
  6. Wait for file copy to complete.
  7. Restart into GUI setup.
  8. Configure regional settings and enter your name.
  9. Enter the product key and computer name.
  10. Set password, date/time, and networking.
  11. Complete setup and log in.
