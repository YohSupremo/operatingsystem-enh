Product Key & Adding Multiple Users

Windows Server 2008 R2 Lab

▶ Watch on YouTube

Overview

Learn how to activate Windows Server 2008 R2 with a product key and efficiently add multiple user accounts through Active Directory Users and Computers. This lab covers the basics of server licensing and user account management.

Steps

  1. Open Server Manager and navigate to server activation.
  2. Enter the Windows Server 2008 R2 product key.
  3. Complete the activation process.
  4. Open Active Directory Users and Computers.
  5. Navigate to the appropriate Organizational Unit (OU).
  6. Right-click and select New > User.
  7. Fill in user details (first name, last name, logon name).
  8. Set the initial password and password policy options.
  9. Repeat for additional users.
  10. Verify all user accounts are created successfully.
