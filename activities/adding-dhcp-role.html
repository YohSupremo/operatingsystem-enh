Adding DHCP Role

Server Role Configuration Lab

▶ Watch on YouTube

Overview

Install and configure the DHCP Server role on Windows Server. This lab covers creating scopes, configuring IP address ranges, setting lease duration, and configuring DHCP options like DNS and default gateway.

Steps

  1. Open Server Manager and click Add Roles.
  2. Select DHCP Server from the roles list.
  3. Complete the DHCP Server role installation wizard.
  4. Open the DHCP management console.
  5. Right-click IPv4 and select New Scope.
  6. Configure the scope name and IP address range.
  7. Set exclusion ranges for static IP addresses.
  8. Configure the lease duration.
  9. Set DHCP options (router/gateway, DNS servers).
  10. Activate the scope.
  11. Authorize the DHCP server in Active Directory.
  12. Test by connecting a client to get an IP automatically.
