Overview

Learn how to install and configure the DHCP Server role on Windows Server. This tutorial covers creating scopes, setting IP address ranges, configuring options like default gateway and DNS, and authorizing the DHCP server in Active Directory.

Key Topics

  1. Install the DHCP Server role via Server Manager.
  2. Authorize the DHCP server in Active Directory.
  3. Create a new DHCP scope with IP range.
  4. Configure scope options (gateway, DNS, lease duration).
  5. Set up exclusion ranges and reservations.
  6. Test DHCP functionality from a client machine.
