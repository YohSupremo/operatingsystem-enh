Windows Server 2008 R2 Installation

Released: 2009

▶ Watch on YouTube

Overview

Windows Server 2008 R2 was the first 64-bit only Windows Server. It featured improved Hyper-V virtualization, Active Directory enhancements, IIS 7.5, PowerShell 2.0, and Server Core installation options.

Installation Steps

  1. Create a virtual machine with 2 GB RAM and 32 GB disk.
  2. Mount the Windows Server 2008 R2 ISO.
  3. Boot from CD and select language settings.
  4. Click Install Now.
  5. Select the edition (Standard/Enterprise/Datacenter).
  6. Accept the license terms.
  7. Choose Custom (advanced) installation.
  8. Select the disk partition and click Next.
  9. Wait for installation and automatic restarts.
  10. Set the administrator password.
  11. Log in and configure initial settings via Server Manager.
  12. Add roles and features as needed.
